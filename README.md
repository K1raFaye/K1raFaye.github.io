# CQB Mapping Tool — 室内近距离战斗模拟器

**by KiraFaye  |  Ver 3.0**

> 纯前端战术标图与 CQB 战术规划工具，打开浏览器即可使用。
>
> 使用方式：访问https://k1rafaye.github.io/

## 技术架构

- **前端语言**：HTML5 + CSS3 + Vanilla JavaScript（ES6 Class）
- **渲染方式**：Canvas 2D API 自绘一切场景元素 + WebGL（Three.js）流体动态背景
- **启动动画**：Ferrofluid 动态背景 + DecryptedText 逐字揭示 + TextType 打字效果
- **外部依赖**：Three.js / GSAP 已本地化至 `vendor/`（仅启动动画使用），核心功能零框架依赖，完全离线可用
- **状态管理**：楼层 → 场景 → 元素三级树结构，配合 JSON 快照历史栈实现撤销/重做（50步）
- **UI 主题**：SpaceX 航空航天美学 + shadcn/ui 语义化设计令牌（纯黑背景 + 光谱白文字 + 幽灵边框）
- **图标系统**：内置 SVG 图标库（icons/）替换全部 emoji 按钮，人员单位使用 PNG 图标
- **布局**：桌面端三栏布局，左右面板支持拖拽调整宽度（记忆到 localStorage）
- **平台**：聚焦桌面端（Ver 3.0 起移除移动端专用模式）

## 核心功能

### 1. 多楼层多场景系统

- 支持多楼层（1F、2F……），可增删移动重命名
- **每个楼层内支持多个独立场景**，场景间完全隔离存储元素与枪线
- 新建场景自动复制前一场景的全部内容
- 场景管理：双击重命名（桌面）/ 长按弹窗操作（移动端）、hover×删除
- 楼梯可绑定目标楼层实现跨层连接

### 2. 建筑元素绘制

| 元素     | 功能                                    |
| ------ | ------------------------------------- |
| 🧱 墙体  | 矩形，任意旋转，遮挡视野                          |
| 🚪 门   | 4向铰链（左/右/上/下）+ 开合角度 0°\~360°，颜色跟随元素属性 |
| 🪟 窗户  | 半透明，不阻挡视野穿透                           |
| 🪜 楼梯  | 跨楼层通道                                 |
| 🚧 遮挡物 | 矩形或圆形，支持旋转                            |

所有元素均支持拖拽、旋转、缩放、改色、标注标签

### 3. 人员单位

- 👤 操作员（友方）— 名称/呼号/职位，可作为枪线起点
- 💀 敌人 — 实战模式下可隐藏，可作为枪线起点
- 🙋 人质 — 不可作为枪线起点
- 人员图标改为内置 PNG（操作员/敌人/人质），未加载完成时回退为几何符号
- 枪线绘制：桌面端右键长按拖动

### 4. 视野遮挡系统（核心特色）

- 扇形 FOV（默认120°），距离可设有限/无限
- **Raycasting 射线投射算法**：72条射线扫描所有障碍物
- 旋转建筑元素按每个角度实时计算遮挡多边形
- 门的开合状态动态影响视野穿透（4向铰链完整支持）
- 可全局开关遮挡显示

### 5. 画板工具

- ✏️ 自由画笔 / ▭ 矩形 / ⭕ 圆形 / 📏 直线 / 🗑️ 区域擦除 / 🧹 清空
- 颜色自由选取，线宽 1\~20px

### 6. 画布缩放与平移

| 操作 | 桌面端            |
| -- | -------------- |
| 缩放 | 鼠标滚轮（以光标为中心）    |
| 平移 | 选择模式+空白处拖拽      |

范围：25% \~ 500%，坐标自动转换

### 7. 智能对齐

- 网格吸附 + 元素边缘吸附（阈值8px）
- **尺寸吸附**：创建时自动匹配已有元素宽高
- 快捷键 S 切换开关

### 8. 其他功能

- ⚔️ 实战模式（隐藏敌方，快捷键 M），开启后顶部指示器 3 秒自动淡出
- ↩️↪️ 撤销/重做（Ctrl+Z/Y）
- 📷 导出 PNG（Ctrl+S）
- 🔲 网格切换（G）

### 9. 启动动画与动态背景

- 打开页面先播放全屏启动动画，点击任意位置进入主界面
- 动画序列：Ferrofluid 全屏 WebGL 流体背景 → "CQB Mapping Tool" 逐字解密揭示 → 叠加渐变流光 + "By KiraFaye" 打字效果
- 主界面初始化由 splash.js 在动画结束后调用（`window.initCQBApp()`）

### 10. 界面交互增强

- **SVG 图标系统**：全部工具栏 / 楼层控制 / 铰链选项 / 设置按钮替换为内置 SVG 图标，激活态自动反色
- **可调面板**：左工具栏与右属性面板之间拖拽调整宽度，限制范围并记忆到 localStorage
- **弹性滑杆**：滑杆拖动时加粗 + 实时数值气泡 + 轨道按当前值渐变填充

### 11. shadcn/ui 设计系统

- 完整语义化 CSS 令牌：`--primary` / `--secondary` / `--destructive` / `--accent` / `--muted` / `--ring` / `--border` 等
- 自定义复选框（隐藏原生控件 + 动画对勾）
- 快捷键 kbd 键帽样式、shadcn 风格 Canvas 提示卡片（Alert）

## 数据架构

```
Layers[]
  └─ Layer { id, name, scenes[], currentSceneId }
       └─ Scene { id, name, elements[], gunlines[] }
            └─ Element { type, x, y, width, height, rotation, color... }
```

撤销/重做快照保存完整的 `scenes[]` 结构，确保跨场景操作可回溯。

## UI 设计

### 视觉风格

- **纯黑背景** `#000000` + **光谱白文字** `#f0f0fa`，通过 shadcn/ui 语义令牌定义
- 半透明幽灵边框/表面（Ghost Surface）、毛玻璃效果
- 大写字母铭牌风格（Impact 字体 + 字间距），正文使用 Segoe UI / Helvetica Neue
- 等宽字体统一为 Consolas / Cascadia Code
- 画布信息改为左上角 HTML 提示卡片（shadcn Alert），不再绘制在画布上

### 楼层管理区布局

```
┌─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
│ 1F 一楼        ▲ ▼ ×    │ ← 名称(粗体) + 按钮(hover显)
│ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ │   细分隔线
│ [场景1] [+]           │ ← 药丸Tab, 激活=反色高亮
└─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘
```

- 操作按钮默认隐藏，hover/active 时淡入
- 场景Tab：点击切换、双击编辑、hover×删除

## 文件说明

| 文件                 | 说明                                     |
| ------------------ | -------------------------------------- |
| `index.html`       | 应用主页面（启动动画层 + 主界面结构）                   |
